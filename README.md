# لاب SSH افتراضي حقيقي (Docker) — بديل سجلات الخادم الفعلي

ليس محاكاة: خادم sshd حقيقي + عملاء يسجلون دخولاً حقيقياً + أدوات هجوم حقيقية (Hydra) في حاويات
Docker منفصلة، كل حاوية بعنوان IP حقيقي خاص بها على شبكة افتراضية. السجل الناتج `auth.log` حقيقي
100% بنفس صيغة أي خادم SSH فعلي، والحقيقة المرجعية معروفة من دور كل حاوية (لا تخمين ولا قاعدة).

## المتطلبات
- Windows 10/11 + **Docker Desktop** (مجاني): https://www.docker.com/products/docker-desktop
- بعد التثبيت فعّل WSL2 إن طلب ذلك، وشغّل Docker Desktop وانتظر حتى تظهر أيقونته خضراء.

## التشغيل
```
cd lab
docker compose build
docker compose up -d --scale attacker_dist=6
```
`--scale attacker_dist=6` ينشئ 6 حاويات مهاجمة بعناوين IP مختلفة حقيقية، فتمثّل الهجوم الموزّع
(distributed) فعلياً بمصادر متعددة حقيقية، لا بمحاكاة.

اتركه يعمل **لا يقل عن 7 أيام**، ويُفضَّل 14 يوماً (القيمة الافتراضية لمدة الهجمات البطيئة والمستخدم
الطبيعي `DURATION_S` مضبوطة على 1,209,600 ثانية = 14 يوماً، عدّلها في `docker-compose.yml` إن أردت مدة
أقصر، أو اتركها، فسيتوقف السكربت تلقائياً بعد المدة ويمكنك التصدير في أي وقت حتى قبل انتهائها).

### تجربة سريعة قبل الانتظار 7 أيام
عدّل `DURATION_S` إلى `600` في الخدمتين `benign_user` و`attacker_slow`، وقلّل `GAP` إلى `30` و`BURSTS`
إلى `2` في بقية المهاجمين، ثم:
```
docker compose up -d --scale attacker_dist=3
```
انتظر 10-15 دقيقة وصدّر السجلات (الخطوة التالية) للتأكد أن كل شيء يعمل، ثم أعد الملفات إلى قيمها
الأصلية وابدأ التشغيل الحقيقي.

## تصدير السجلات (في أي وقت)
```
bash export_logs.sh real_lab_export
```
ينتج `real_lab_export/auth.log` (سجل حقيقي) و`real_lab_export/network_map.json` (خريطة IP ← دور).

## تحويلها لملف التجارب
```
python label_from_lab.py --log real_lab_export/auth.log --map real_lab_export/network_map.json \
    --out D1.csv --salt اكتب_كلمة_سرية
python bf_eval.py --data D1=D1.csv --out results --seeds 10 --boot 1000
```
لا تضف `--auto-scenario`: الوسوم هنا حقيقية من دور الحاوية وليست تقديرية.

## إيقاف اللاب
```
docker compose down
```

## ما يجعل هذا "حقيقياً" للورقة
- بروتوكول SSH حقيقي كامل (مصافحة، مصادقة، فشل/نجاح) وليس توليداً نصياً لسطور سجل.
- Hydra أداة هجوم حقيقية يستخدمها مهاجمون فعليون، وليست سكربت محاكاة.
- كل مصدر هجوم حاوية بعنوان IP حقيقي مختلف فعلاً على الشبكة، فالهجوم الموزّع حقيقي لا مُصطنع.
- التزامن الزمني حقيقي (ثوانٍ ودقائق وساعات فعلية)، فخصائص الفواصل الزمنية (gap/CV) تُقاس على
  توقيت حقيقي لا على توقيت مُصطنع.
- الحقيقة المرجعية مستقلة عن أي ميزة من ميزات الكاشف (مأخوذة من دور الحاوية)، فلا دائرية في النتائج.

## ما يبقى قيداً يجب ذكره في الورقة
- بيئة مغلقة (lab) على جهازك وليست إنتاجاً حياً حقيقياً (production)، فذكر ذلك صراحة في القيود.
- عدد المستخدمين الطبيعيين خمسة فقط، أقل تنوعاً من مؤسسة حقيقية؛ عدّل `server/make_users.sh`
  و`benign/benign.sh` لزيادتهم إن أردت.
- حركة المرور الطبيعية مولَّدة بجدول عشوائي واقعي (نمط يومي، كلمات مرور خاطئة أحياناً)، وليست
  سجلات مستخدمين حقيقيين فعليين، فهذا أضعف من سجلات مؤسسة حقيقية لكنه أقوى بكثير من بيانات اصطناعية
  مُولَّدة بالكامل دون أي بروتوكول أو أداة حقيقية.
